# Index terms for the Councils volumes
#
# One entry per line:   Index heading | other spelling | other spelling | options
#
#   Matching ignores letter case, except variants that start with "="  (=Leo matches "Leo", not "leonine").
#   A variant ending in "*" matches any word starting with it        (anathem* = anathema, anathematised).
#   If a heading has a comma or brackets, list what to look for as variants;
#   otherwise the heading itself is searched for too.
#
#   Options:
#     #3-7        only look in councils 3 to 7        (#19 or #4,6,8-10 also work)
#     see: X      print "see X" under this heading     (use with no variants for a pure cross-reference)
#     see also: X print "see also X" after the page numbers
#
#   Notes and footnotes sections are not indexed (they are mostly citations).
#   Lines starting with # are comments; [Group] lines are only for your reading.
#   Re-run book_print.py after editing: page numbers are recalculated every time.
